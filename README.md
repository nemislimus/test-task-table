# Task Table Management

Веб-приложение для управления задачами разработчиков с интерактивной таблицей и переключением между режимами просмотра.

## 🚀 Демо

[![Live Demo](https://img.shields.io/badge/🚀-Live_Demo-green?style=for-the-badge)](https://nemislimus.github.io/test-task-table/)

![preview](https://github.com/user-attachments/assets/5c56ca6e-bb83-40cf-b54b-eedc67540268)

## ✨ Особенности

- 📊 Двухрежимная таблица (Разработчики ↔ Задачи)
- 🎨 Дизайн с Shadcn
- 🏪 Централизованное управление состоянием через Zustand
- 🧪 Полное покрытие unit-тестами
- ⌨️ Типобезопасность TypeScript

## 🛠️ Технологии

### Frontend
- **React 18** - UI библиотека
- **TypeScript** - типизация
- **Vite** - сборка и dev-сервер

### Стилизация
- **Tailwind CSS** - утилитарные CSS-классы
- **Shadcn/ui** - компоненты таблицы

### State Management
- **Zustand** - легковесное управление состоянием

### Тестирование
- **Vitest** - test runner
- **Testing Library** - тестирование компонентов
- **JSDOM** - браузерное окружение для тестов
